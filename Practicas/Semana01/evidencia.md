## ¿Qué recibe el navegador?

1. ¿Qué archivo solicitó el navegador?
Solicitó una petición para mandar a llamar al archivo `index.php`.

2. **¿Qué código de respuesta recibió?**
El de aceptación, verificación bien, el 200.

3. **¿Qué contenido recibió?**
Recibió solamente el código HTML, ya que el PHP se ejecuta y simplemente se imprime en el HTML.

4. **¿Puedes encontrar literalmente el código PHP que escribiste?**
No, no se puede encontrar, ya que eso es algo que solo es la lógica.

5. **¿Por qué?**
Porque el servidor se encarga de la lógica y de las variables, y el navegador solo de la vista del frontend HTML.
