# 🏆 Práctica 15 — Desarrollo de Aplicaciones Web (Presentación del Proyecto Final)

## Objetivo
Presentar y demostrar en funcionamiento el **Gestor de Inventario**, explicando el problema que resuelve, su arquitectura MVC, sus componentes reutilizables, el uso de Fetch API con JSON, el control de acceso por roles, las medidas de seguridad en el servidor, las funciones avanzadas y los resultados de las pruebas de integración.
